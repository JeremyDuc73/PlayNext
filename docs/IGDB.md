# Recherche manuelle IGDB

IGDB est utilisé uniquement pour les jeux ajoutés manuellement :

- rechercher un titre commun entre les launchers ;
- conserver l’identifiant IGDB ;
- partager une même référence dans les groupes ;
- récupérer une cover de base pour cette entrée.

Le catalogue automatique des bibliothèques ne dépend pas d’IGDB.

Configuration locale :

```env
TWITCH_CLIENT_ID=...
TWITCH_CLIENT_SECRET=...
```

Les clés viennent d’une application Twitch **Confidential** :
<https://dev.twitch.tv/console/apps>

Dans la bibliothèque personnelle : **Ajouter un jeu** → recherche → **Ajouter**.
